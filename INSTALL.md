# Install

1. Replace README.md in https://github.com/endse/endse with the included README.md.
2. Add `.github/workflows/snake.yml` at that exact path in the profile repository.
3. In the repository settings, make sure GitHub Actions can write repository contents.
4. Run Actions → Generate contribution snake → Run workflow.
5. Confirm the `output` branch appears. The snake will display after the first successful run.

Notes:
- Keep the language and technology rows using skillicons.dev.
- GitHub Stats, Top Languages, Streak and Activity Graph are remote image services. If GitHub stats cards temporarily fail, the skills section and the native GitHub contribution link remain useful.
- The six requested flagship repository URLs are retained exactly as supplied.
